# etoprosto-test

Тестовое задание.

Скрипт `naive.py` просто скопирован из LLM. Скрипт `asynchronous.py` представляет собой вручную модифицированную версию того же
скрипта, но с использованием асинхронного программирования для ускорения выполнения.

Единицы скорости: МБ/сек.

## Запуск

Для запуска нужно выполнить команду:
```console
python <script name>.py <URL>
```

URL должен содержать `www`; `http(s)://` можно опустить.
